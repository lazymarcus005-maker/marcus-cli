## Current verification seam

The approved tracer-bullet seam is the public `macus` CLI. Tests drive its command entrypoint and session boundary, with deterministic adapters/mocks rather than contacting a live model. Feature-specific tests should remain user-observable through CLI behavior or the stable internal adapter boundary.
