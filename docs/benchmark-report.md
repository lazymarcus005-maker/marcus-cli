Status: **recorded controlled paired run on the deterministic loopback provider; no live-endpoint or reference-hardware measurement exists.**

This report records the first controlled paired Macus-versus-unmodified-Pi
benchmark run produced by the harness in `src/workflow/benchmark.ts`. It was
generated by `scripts/run-paired-benchmark.ts` against a deterministic

## Known limitations of this evidence

- The provider is a local fixture, not a real model endpoint. No live-endpoint
  compatibility, quality, latency, or token-cost conclusion is supported.
- Both adapters are in-process; isolated CLI peak RSS and first-useful-edit
  time remain unmeasured (`null` in every observation).
- The fixture corpus used here is a one-file repository; the deterministic
  10,000-file reference fixture (`npm run benchmark:fixture`) has been
  validated for generation but has not been used for a paired measurement.
- The machine used is the spec §39 reference hardware (Mac mini M4 Pro 48 GB,
  macOS arm64), but the endpoint is the local fixture; reference-hardware
  performance targets against a real model endpoint remain unmeasured.

No performance, equivalence, or improvement claim is made by this report.
Live-endpoint paired measurement remains a release blocker tracked in
`docs/phase-7-evidence.md`.
